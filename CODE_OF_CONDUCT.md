# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

## In short

Be respectful. Assume the other person is acting in good faith. Criticise the
code, not the person who wrote it. Harassment, personal attacks, and unwelcome
attention are not tolerated, in issues, pull requests, commit messages, or
anywhere else the project is discussed.

## Reporting

Report a problem privately to the maintainer, by email — the address is in the
git history. Reports are handled confidentially. The maintainer will respond,
and may warn, temporarily block, or permanently ban anyone whose behaviour
warrants it.

Reporting in good faith carries no penalty, whatever the outcome of the report.
